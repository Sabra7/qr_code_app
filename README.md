# QR Code Generator

A lightweight, ad-free desktop application built with Python and CustomTkinter. Features a sleek, modern dark UI inspired by Android Material Design 3 and Windows 11.

---

## Why I Built This

I built this app out of pure boredom and because I got tired of online QR code generators filled with aggressive ads, pop-ups, and slow load times. This is a simple, clean, and offline tool that gets the job done instantly.

---

## Features

- **Modern Dark UI:** Clean interface with rounded corners and smooth layout.
- **Instant Preview & Auto-Save:** Generates and previews QR codes immediately, saving them automatically to the `Generated QR` folder.
- **Clipboard Integration:** Copy generated QR images directly to your clipboard to paste anywhere.
- **Cross-Language Shortcuts:** Keyboard shortcuts (`Ctrl+A`, `Ctrl+C`, `Ctrl+V`, `Ctrl+X`) work seamlessly regardless of whether your active input language is English or Arabic.
- **100% Offline & Ad-Free:** Runs locally on your machine with zero clutter.

---
